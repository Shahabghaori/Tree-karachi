# 🌳 Tree-Karachi: Tree Canopy Mapping

## Project Overview
This project focuses on mapping the spatial distribution of tree canopy across Karachi, Pakistan, using Google Earth Engine (GEE) and remote sensing techniques.

The aim is to examine the distribution of tree canopy and identify areas with different levels of vegetation cover.

## Study Area
Karachi, Sindh, Pakistan.

## Data Sources
- Freely available satellite-derived canopy-height data.
- Karachi study-area boundary.

## Tools and Technologies
- Google Earth Engine
- JavaScript
- GIS
- Remote Sensing

## Methodology
1. Define the Karachi study area.
2. Access canopy-height data in Google Earth Engine.
3. Process the dataset for the study area.
4. Apply a 3-metre canopy-height threshold.
5. Generate tree-canopy and canopy-height maps.
6. Export results for further GIS analysis.

## Project Outputs
- Karachi tree-canopy map (3 m threshold).
- Karachi canopy-height raster.
- Google Earth Engine scripts.

## Project Status
Initial mapping and data export completed. Further analysis and validation are ongoing.
